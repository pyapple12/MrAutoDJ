## 4. 尺寸基准（供 Qt 布局）

- 总画板：1280×800（等比缩放自 1600×1000 FLX4）
- 四区分割：Browse 高 5%、Deck 各 35% 宽、Mixer 30% 宽、Effects 20% 宽
- Jog 转盘：140×140（M1.5 现有尺寸）
- Pad 阵列：2×4，每键 35×35，间距 5
- 推子行程：80px（垂直/水平）
- 旋钮：28×28

## 5. 交互语义（FLX4 参照）

- LOAD 双按 = Instant Doubles（已有）
- Jog 顶面：Vinyl 开=搓碟、Vinyl 关/外圈=弯音（已有）
- SHIFT + 按键 = 第二功能（已有）
- Pad 5 模式：Hot Cue/Beat Loop/Beat Jump/Sampler/Key Shift（已有）
- Beat FX：通道选择→效果选择→拍数→DEPTH→ON（需 UI 适配新视觉）
